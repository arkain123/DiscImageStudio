<h2>Универсальный инструмент для создания и записи видимых изображений на оптические диски</h2>

Disc Image Studio — это программа для Windows, предназначенная для создания и записи изображений на рабочую поверхность оптических дисков. Она позволяет наносить видимые невооружённым глазом изображения на **любые** DVD / CD / Blu-ray с помощью **любого** записывающего оптического привода.

## Обзор

Disc Image Studio преобразует изображение в данные, соответствующие ограничениям физического уровня CD, DVD и однослойных дисков BD-R. После записи на поверхности диска появляется рисунок, видимый невооружённым глазом.

## Быстрый старт

Скачайте Release EXE со страницы [GitHub Releases](https://github.com/JiaFeiMiao-K-Cat/DiscImageStudio/releases), распакуйте его и запустите напрямую. EXE уже содержит среду выполнения .NET.

### 1. Создайте проект

На главной странице выберите CD, DVD или Blu-ray, укажите место сохранения и создайте проект.

### 2. Создайте дизайн поверхности диска

Импортируйте изображение на странице «Дизайн», расположите его с помощью слоёв и настройте дизеринг, гамму, яркость и уровни серого в панели **«Тон»** справа.

### 3. Предварительный просмотр и экспорт

Проверьте проекцию изображения на странице предварительного просмотра, затем на странице экспорта создайте ISO / RAW / WAV+CUE либо воспользуйтесь функцией потоковой записи для непосредственной записи на чистый диск.

Потоковая запись является экспериментальной функцией. Используйте только тестовые носители, которые не жалко испортить.

## Возможности

### Генерация данных для дисков

- **Поддержка CD**: поддерживаются любые CD. Можно экспортировать звуковые дорожки WAV с заголовками формата и сопутствующие файлы CUE, совместимые с такими программами записи, как cdrecord и ImgBurn; также доступен экспорт звуковых дорожек RAW. См. [совместимость записи CD](docs/CD_AUDIO_COMPATIBILITY.md).
- **Поддержка DVD**: поддерживаются любые DVD. Можно экспортировать ISO-образы.
- **Поддержка Blu-ray**: поддерживаются любые однослойные BD-R объёмом 25 ГБ, включая режим только с рисунком и файлы UDF 2.01. См. [ADDING_BLURAY.md](docs/ADDING_BLURAY.md).
- **Файлы на диске**: для CD, DVD и Blu-ray можно выбрать папку и разместить её файлы во внутренней или внешней области диска непосредственно на странице «Дизайн» либо изменить эти параметры на странице экспорта. Настройки сохраняются вместе с проектом.
- **Предварительный просмотр области файлов**: в проекции гибридного диска и при моделировании считывания готового результата область файлов, включая файловую систему, выделяется жёлтым цветом.
- **Схемы оттенков для носителей**: CD и DVD используют два чёрно-белых уровня: `0D / AA` для CD и `A5 / 92` в скремблированном пространстве DVD. См. [PHYSICAL_MODEL_AUDIT.md](docs/PHYSICAL_MODEL_AUDIT.md).
- **Инструмент дизеринга оттенков серого**: отдельная программа также умеет преобразовывать исходное изображение в двухуровневый чёрно-белый PNG `0/255`. Поддерживаются открытие файла или перетаскивание изображения, параллельный просмотр оригинала и результата, а также экспорт PNG без потерь. См. [инструкцию по использованию и сборке](tools/FourLevelDither/README.md).
- **Предустановки дисков**: встроенные параметры дисков охватывают несколько брендов CD, DVD и BD. Вы также можете добавить собственные откалиброванные данные; см. [обслуживание предустановок](docs/DISC_PRESETS.md).

### Вспомогательная калибровка

Disc Image Studio предоставляет интеллектуальный и точный процесс вспомогательной калибровки. По сравнению с ручной визуальной калибровкой алгоритм вспомогательной калибровки повышает точность определяемых физических параметров поверхности диска с 10<sup>-6</sup> до 10<sup>-14</sup>. До калибровки постоянный шаг дорожки приводит к заметному искривлению радиальных линий перекрестия. После повторной генерации и записи с использованием параметров кубического шага дорожки, полученных посредством вспомогательной калибровки, линии становятся ближе к прямым радиальным линиям.

| До калибровки · Постоянный шаг дорожки | После калибровки · Кубический шаг дорожки |
| --- | --- |
| ![Фото DVD до калибровки: радиальные линии перекрестия заметно искривлены](docs/images/verbatim-dvd-calibration-before.jpg) | ![Фото DVD после калибровки: радиальные линии стали ближе к прямым](docs/images/verbatim-dvd-calibration-after.jpg) |
| `P20261004-133519.jpg` | `P20261004-135416.jpg` |

Описание процесса и параметров см. в [руководстве по вспомогательной калибровке](docs/CALIBRATION.md).

### Запись

- **Вывод образа диска**: можно экспортировать полные файлы ISO / RAW и записывать их вручную подходящей программой.
- **Потоковая запись в реальном времени (экспериментальная)**: данные CD, DVD и BD-R генерируются и записываются одновременно, без сохранения полного образа диска. Для BD-R используется последовательная запись MMC.
- **Не используйте непустые носители!**

### Приложение

- Многоязычный интерфейс: нажмите **«Настройки»** в правом верхнем углу, затем в разделе **«Общие → Язык»** выберите упрощённый китайский, традиционный китайский, английский или **«Системный»**. Сохраните настройки и перезапустите приложение, чтобы применить изменение языка. По умолчанию язык и тема следуют системным настройкам; явно сохранённые ранее параметры сохраняются. При системном языке `zh-TW`, `zh-HK`, `zh-MO` и `zh-Hant` используется традиционный китайский, для остальных китайских локалей — упрощённый китайский, а для всех прочих языков — английский.
- Два режима запуска: без аргументов открывается графический интерфейс, с аргументами используется единая командная строка.
- Модульная архитектура: CD, DVD и Blu-ray подключаются через `IOpticalDiscModule` и используют общий каталог команд и контракты задач. См. [руководство по архитектуре](docs/ARCHITECTURE.md).

## Системные требования и требования к оборудованию

- Windows 10 2004 (2004/20H1, 19041) или новее либо Windows 11.
- Для сборки: .NET 10 SDK (`global.json` фиксирует версию 10.0.x). Для графического интерфейса, собранного из исходников без self-contained runtime, требуется .NET 10 Windows Desktop Runtime. Release EXE уже содержит runtime, поэтому отдельно устанавливать .NET не нужно.
- Для потоковой записи требуется распознаваемый Windows привод CD / DVD / BD и чистый носитель. Для BD-R требуется чистый однослойный диск с поддержкой последовательной записи.

## Сборка и запуск

```powershell
dotnet build DiscImageStudio.slnx --configuration Release
dotnet run --project src/DiscImageStudio.App --configuration Release
```

Проверки регрессий сборки:

```powershell
dotnet run --project src/DvdImageSolver --configuration Release -- selftest
dotnet run --project tests/DiscImageStudio.ArchitectureTests --configuration Release
```

Правила версионирования, создание EXE в CI, проверка черновика релиза, упаковка MSIX и процедуры подписи описаны в [руководстве по выпуску](docs/RELEASING.md).

## Командная строка

При запуске без аргументов единая программа открывает графический интерфейс, а при передаче аргументов работает как инструмент автоматизации:

| Команда | Описание |
| --- | --- |
| `solve` | Создать DVD-образ с использованием фиксированного быстрого текстурного отображения (направление CW), с необязательным дизерингом для смешивания чёрных и белых текстур |
| `encode` | Закодировать один ECC-блок DVD в уровни канала NRZI |
| `calibrate` | Калибровочная проекция: выбрать данные из исходного изображения DVD по геометрии генерации и спроецировать их на диск с использованием измеренной геометрии |
| `simulate` | Смоделировать считывание созданного DVD ISO с использованием измеренных радиусов |
| `selftest` | Запустить детерминированные регрессионные самотесты DVD-движка |
| `cd-generate` | Создать аудиодорожки WAV + CUE / RAW, если файлы на диск не добавляются; при указании `--data-dir` создать ISO диска CD с данными |
| `cd-preview-warp` | Калибровочная проекция: спроецировать исходное изображение CD с использованием измеренной геометрии |
| `cd-preview-track` | Отрисовать существующую дорожку WAV или RAW CD-DA с использованием откалиброванной геометрии (моделирование считывания) |
| `bd-generate` | Создать полный ISO-образ BD-R и записать сопутствующий файл `<iso>.json` |
| `bd-info` / `bd-probe` / `bd-encode` | Вывести параметры BD, необработанные пробы полезной нагрузки или диагностику одного ECC-кластера |

Полный список параметров каждой команды см. в соответствующей документации.

## Используемые стандарты

Реализация и физические модели Disc Image Studio в основном опираются на следующие спецификации:

| Носитель | Стандарт и редакция | Используемая в проекте область |
| --- | --- | --- |
| CD-R | [ECMA-394, 1-я редакция, декабрь 2010](https://ecma-international.org/publications-and-standards/standards/ecma-394/) — *Recordable Compact Disc Systems CD-R Multi-Speed* ([официальный PDF](https://ecma-international.org/wp-content/uploads/ECMA-394_1st_edition_december_2010.pdf)) | Носители CD-R, многоскоростная запись и совместимость CD-DA; проект создаёт аудиодорожки CD-DA. |
| Общий формат DVD / DVD-ROM | [ECMA-267, 3-я редакция, апрель 2001](https://ecma-international.org/publications-and-standards/standards/ecma-267/) — *120 mm DVD – Read-only disk* ([официальный PDF](https://ecma-international.org/wp-content/uploads/ECMA-267_3rd_edition_april_2001.pdf)) | Кадры данных DVD, ECC, кодирование EFMPlus и таблицы преобразования приложения G; для правил записываемых носителей также используется ECMA-359. |
| DVD-R | [ECMA-359, 1-я редакция, декабрь 2004](https://ecma-international.org/publications-and-standards/standards/ecma-359/) — *80 mm (1,46 Gbytes per side) and 120 mm (4,70 Gbytes per side) DVD Recordable Disk (DVD-R)* ([официальный PDF](https://ecma-international.org/wp-content/uploads/ECMA-359_1st_edition_december_2004.pdf)) | Геометрия однослойного DVD-R, секторы, коррекция ошибок и кодирование; стандарт охватывает односторонние и двусторонние носители. Двусторонний диск не означает двухслойный. |
| BD-R | [ISO/IEC 30190:2021, 3-я редакция, январь 2021](https://www.iso.org/standard/80770.html) — спецификация обмена и хранения информации на записываемых BD диаметром 120 мм, однослойных (25,0 ГБ) и двухслойных (50,0 ГБ) | Экспериментальный режим использует схему дорожек и секторов, коррекцию ошибок и кодирование для однослойных дисков 25 ГБ. Двухслойные диски в настоящее время не поддерживаются. |

Общие компоненты кодирования CD также используют [ECMA-130, 2-я редакция (CD-ROM, 1996)](https://ecma-international.org/publications-and-standards/standards/ecma-130/).

## Безопасность записи и носителей

- Disc Image Studio не устанавливает драйверы или службы. Потоковая запись использует встроенный в Windows IMAPI2 и отклоняет непустые носители.
- По потоковой записи уже получены некоторые результаты тестирования на физических дисках, однако охват разных устройств, носителей и способов записи всё ещё ограничен. Функция экспериментальная; используйте только расходные тестовые носители. Прерывание записи, отключение питания или недостаточная скорость генерации всё ещё могут сделать диск непригодным!
- Фактический видимый результат зависит от диска, привода, прошивки и стратегии записи.
- Для гибридных дисков исходная папка сканируется, а её структура фиксируется до начала записи. Если размер исходного файла изменится во время операции, задача будет безопасно завершена; однако диск, запись которого уже началась, всё равно может стать непригодным.
- Последовательная запись BD-R не предусматривает переназначение резервной области. После прерывания обычно невозможно продолжить запись на тот же диск.

## Конфиденциальность и безопасность

- Disc Image Studio не обращается к сети, не загружает файлы и не собирает телеметрию. См. [политику конфиденциальности](PRIVACY.md).
- Не публикуйте сведения об уязвимостях в открытых Issues. Следуйте [политике безопасности](SECURITY.md) и используйте функцию приватного сообщения об уязвимостях GitHub.
