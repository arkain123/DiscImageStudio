# Редактируемые пресеты дисков

Пресеты дисков делятся на два слоя:

- Встроенный слой поставляется и обновляется вместе с приложением и хранит официальные пресеты.
- Пользовательский слой находится в следующем файле и хранит только добавленные, переопределённые и отключённые пользователем настройки:

```text
%LOCALAPPDATA%\DiscImageStudio\disc-presets.json
```

При первом запуске программа помещает в пользовательский слой три редактируемых пресета: «Пользовательские параметры CD», «Пользовательские параметры DVD» и «Пользовательские параметры Blu-ray». Встроенные пресеты не копируются в пользовательский файл, поэтому исправления параметров и новые пресеты после обновления приложения вступают в силу автоматически.

Добавление пользовательского пресета выполняется в диалоге настроек проекта: «Сохранить этот набор параметров как пресет» сначала открывает отдельное окно для подтверждения имени, затем добавляет текущие параметры в пользовательский слой; список шаблонов при создании проекта показывает все не ручные пресеты из каталога, сгруппированные по «Недавние», «CD», «DVD» и «Blu-ray».

Диалог настроек проекта также перечисляет пресеты текущего типа диска: выбор другого пресета перезаписывает геометрические параметры в диалоге, поэтому перед переключением появляется подтверждение; при отмене исходные параметры сохраняются, а выбранный элемент не меняется. Пользовательские пресеты в окне создания проекта и в настройках проекта можно удалить через контекстное меню; удаление сразу записывается в пользовательский слой и обновляет список; после прямого редактирования JSON (добавление, переименование, отключение) всё ещё требуется перезапуск программы.

## Правила объединения

- Если пользовательский пресет использует новый `id`, он добавляется после встроенных пресетов.
- Если пользовательский пресет использует тот же `id`, что и встроенный, он полностью переопределяет этот встроенный пресет.
- `disabledCdPresetIds`, `disabledDvdPresetIds` и `disabledBluRayPresetIds` могут скрыть ненужные встроенные или пользовательские пресеты.
- При обновлении встроенного пресета параметры, не переопределённые пользовательским элементом с тем же ID, обновляются автоматически.

## Добавление пресета DVD

В массиве `dvdPresets` скопируйте инициализированный пользовательский объект и измените `id`, имя и параметры. Например:

```json
{
  "id": "verbatim-dvd-r-azo-43533",
  "displayName": "Verbatim DVD-R AZO (43533) (измеренный)",
  "description": "Проверенные калибровочные параметры Verbatim DVD-R AZO 43533: 23.9914606277–57.9648936579 mm, всего 2 297 888 секторов; используется кубическое распределение шага дорожек.",
  "totalSectors": 2297888,
  "innerRadiusMm": 23.991460627731737,
  "outerRadiusMm": 57.964893657925366,
  "channelBitLengthNm": 133.3,
  "pitchLinear": -3.9256854319227684E-05,
  "pitchQuadratic": 6.964795915429256E-05,
  "pitchCubic": -4.670918950137523E-05
}
```

`totalSectors` DVD должен быть больше 0 и кратен 16, чтобы удовлетворять требованиям ECC Block и компоновки потоковой записи. `channelBitLengthNm` см. в следующем разделе; это зарезервированное поле.

Этот пресет Verbatim DVD взят из подтверждённого пользователем проверенного `calibration-f2f851f7.calibration.json`; сохранена полная точность параметров из записи.

`pitchLinear`, `pitchQuadratic`, `pitchCubic` — три относительных коэффициента формы кубического шага дорожек, по умолчанию равны 0 для совместимости со старыми пресетами. Модель: `p(x)=p0*(1+pitchLinear*x+pitchQuadratic*x²+pitchCubic*x³)`, `x=(r-innerRadiusMm)/(outerRadiusMm-innerRadiusMm)`. Полный полином содержит четыре члена; `p0` автоматически вычисляется по общей длине дорожки, а интерфейс показывает фактические значения четырёх членов в μm. На всём интервале `0≤x≤1` шаг дорожек должен быть строго положительным; нельзя проверять только внутреннюю и внешнюю границы. Изменение любого коэффициента переключает в несохранённое пользовательское состояние; повторный выбор встроенного пресета с постоянным шагом дорожек восстанавливает нулевые коэффициенты.

## Добавление пресета CD

В массиве `cdPresets` скопируйте существующий объект и измените `id`, имя, число секторов и внутренний/внешний радиусы. Например:

```json
{
  "id": "cd-74",
  "displayName": "Стандартный CD 74 min",
  "description": "Стандартная скорость ECMA-130 / ISO/IEC 10149 1200 mm/s; диск 120 mm, около 74 минут, 333 000 секторов (24,5–56,8 mm).",
  "sectors": 333000,
  "innerRadiusMm": 24.5,
  "outerRadiusMm": 56.8,
  "linearVelocityMmPerSecond": 1200
}
```

## Добавление пресета Blu-ray

В массиве `bluRayPresets` скопируйте существующий объект и измените `id`, имя и параметры. Например:

```json
{
  "id": "bd-r-ritek-10x",
  "displayName": "Ritek BD-R 10x (измеренный)",
  "description": "Измеренные параметры: внутренний радиус 23.988221 mm, внешний радиус 58.023235 mm, 12 219 392 сектора.",
  "totalSectors": 12219392,
  "innerRadiusMm": 23.98822105616562,
  "outerRadiusMm": 58.023234731100764,
  "invertMapping": false
}
```

`totalSectors` BD должен быть больше 0, выровнен по 32 и не превышать ёмкость однослойного диска 12 219 392; внешний радиус не должен превышать 60 mm. `invertMapping` — предустановленная полярность 3T/6T; после применения к проекту её всё ещё можно изменить в модуле тона на странице дизайна.

Встроенный `bd-r-verbatim-64099` (Verbatim BD-R (64099)) использует сохранённый в пользовательском файле `disc-presets.json` пресет «Verbatim 64099» с полной точностью: внутренний радиус `23.987042157339335` mm, внешний радиус `57.987960341783236` mm, `12 219 392` сектора, `invertMapping: false`. GUI и командная строка используют одинаковые параметры.

## Фиксированные параметры и зарезервированные поля

Скорость сканирования, начальный угол, внешний радиус изображения и длина канального бита DVD — фиксированные физические величины схемы; интерфейс не предоставляет соответствующих форм, и при генерации программа всегда использует 1200 mm/s (ECMA-130), 0°, 57,5 mm и 133,3 nm.

Они всё ещё сохраняются как поля в JSON, потому что в старых версиях конфигурационных файлов эти параметры были обязательными, поэтому нужно обеспечить возможность напрямую использовать пользовательские файлы, записанные старыми версиями. Эти два значения не участвуют в вычислениях генерации.

## Поля совместимости i18n

В формате уже зарезервированы необязательные `fallbackLanguage`, `displayNameResourceKey` и `descriptionResourceKey`. Текущая версия по-прежнему напрямую отображает `displayName` и `description`; при будущем подключении многоязычных ресурсов сначала будут разрешаться ключи ресурсов, а существующий текст будет использоваться как fallback, поэтому повторно обновлять структуру JSON не потребуется. Пользовательским пресетам не нужно заполнять ключи ресурсов.

## Правила редактирования

- Текущий верхний уровень — `"schemaVersion": 4`, содержит `cdPresets`, `dvdPresets`, `bluRayPresets`, три списка отключённых и необязательный `fallbackLanguage`. Программа также принимает `"schemaVersion": 2` и `3`; при отсутствии каталога BD он дополняется встроенными шаблонами BD, а при сохранении выполняется обновление до 4.
- `id` в каждой группе пресетов должен быть уникальным; `__manual__` — зарезервированный ID для состояния интерфейса «несохранённые пользовательские параметры», его нельзя записывать в JSON.
- Можно заполнять только перечисленные в шаблоне параметры генерации; другие поля будут отклонены, чтобы не смешивать компоновку изображения или параметры калибровки с пресетами дисков.
- Радиусы, `linearVelocityMmPerSecond` и `channelBitLengthNm` должны быть конечными числами больше 0; сгенерированный внешний радиус должен быть больше сгенерированного внутреннего радиуса.
- В файле допускаются комментарии `//` или `/* ... */`, а также запятая в конце массива.
- Если формат или параметры недействительны, программа укажет проблему и продолжит использовать последний успешно загруженный набор пресетов, не перезаписывая автоматически пользовательский файл.
