# Интернационализация интерфейса

Нажмите постоянно присутствующую в правом верхнем углу кнопку «шестерёнка + настройки», в разделе «Общие → Язык» выберите «Следовать системе», «简体中文», «繁體中文» или «English»; изменения вступят в силу после сохранения и перезапуска. Кнопка настроек отображается на главной странице и во всех рабочих областях, её также можно открыть сочетанием Ctrl+,; в меню «…» остаётся только пункт «О программе». Отмена, Escape или закрытие окна настроек не сохраняют язык. Переключение языка не перезапускает приложение автоматически, не закрывает проект и не прерывает задачи.

`language` в `settings.json` принимает значения `system`, `zh-CN`, `zh-TW` или `en`. Язык и тема по умолчанию следуют системе; отсутствующее, пустое или неподдерживаемое значение языка также откатывается к следованию системе, при этом действительные выборы языка и темы в существующей конфигурации остаются неизменными. При следовании системе используется язык системного UI на момент запуска: `zh-TW`, `zh-HK`, `zh-MO`, `zh-Hant` и явно заданные `zh-Hant-*` используют традиционный китайский; `zh-CN`, `zh-SG`, `zh-Hans` и другие китайские системы используют упрощённый китайский; английская, японская, французская и другие некитайские системы единообразно используют английский. Изменение системного языка во время работы требует перезапуска приложения. Тема использует режим цвета приложений Windows для выбора тёмного или светлого оформления. Язык не зависит от `.discproj`; имя проекта, имена пользовательских предустановок, имена слоёв, пути к файлам и правила разбора чисел не участвуют в переводе.

## Добавление и сопровождение текстов

Переводы находятся в `src/DiscImageStudio.App/Localization/Catalogs/*.json`, встраиваются в сборку при сборке и не требуют дополнительных зависимостей во время выполнения. Каждый ключ содержит тексты для `zh-CN`, `zh-TW` и `en`; традиционный китайский использует отдельный ресурс с такими терминами, как «設定», «專案», «檔案», «燒錄», и не преобразует пользовательские данные во время выполнения:

```json
{
  "示例 {0}": { "zh-CN": "示例 {0}", "zh-TW": "範例 {0}", "en": "Example {0}" }
}
```

В C# используется `L.T("源文案")`, для интерполяции — `L.F($"示例 {value}")`, ключом ресурса является его .NET-строка составного формата `示例 {0}`; если нужен явный ключ ресурса, можно использовать `L.Format(key, arguments)`. В переводе можно менять порядок параметров, но необходимо сохранять индексы и спецификаторы формата. В XAML используются `xmlns:loc="clr-namespace:DiscImageStudio.Localization"` и `{loc:Text ResourceKey}`, которые разрешаются при создании окон и шаблонов.

Общие фразы нужно определять только один раз; ключи во всех файлах ресурсов должны быть уникальными. Если текущий язык не найден, используется китайский; если ключ отсутствует, отображается сам ключ. При запуске сначала инициализируется язык, затем создаются окна и ViewModel. Устанавливается только UI culture, numeric culture сохраняется; не переводите идентификаторы протоколов, команды, пути, пользовательские данные и не используйте переведённый текст для логических проверок.

Область охвата — интерфейс настольного приложения и сообщения уровня приложения; независимая справка командной строки, диагностика низкоуровневого кодера и ошибки сторонних компонентов/ОС остаются на своих языках, исходный текст лицензий не изменяется.

## Проверка

`LocalizationTests` проверяет полноту языков ресурсов, параметры формата, откат к системному языку, поведение сохранения и отмены настроек, а также то, что сбой сохранения не применяет язык.

```powershell
dotnet run --project src/DiscImageStudio.App -c Release -- ui-snapshot --settings-dialog --language en --output artifacts/settings-en.png
dotnet run --project src/DiscImageStudio.App -c Release -- ui-snapshot --settings-dialog --language zh-CN --output artifacts/settings-zh.png
dotnet run --project src/DiscImageStudio.App -c Release -- ui-snapshot --settings-dialog --language zh-TW --output artifacts/settings-tw.png
```

Снимки экрана используют одноразовый файл настроек и не изменяют пользовательскую конфигурацию. При добавлении языка также расширяйте правила нормализации и разбора языка, варианты в выпадающем списке настроек, соответствующие ресурсы и тесты.
